# مساعد BCBA الذكي

نموذج أولي لمشروع أولمبياد «إبداع»: ذكاء اصطناعي مساعد لأخصائي تحليل السلوك (BCBA).

- يرصد سلوكيات حركية معرّفة تشغيليًا تختارها الأخصائية في كل جلسة: رفع اليد، التصفيق، القيام من الكرسي، رفرفة اليدين، التأرجح بالجسم، القفز المتكرر، الدوران حول النفس، مغادرة الكرسي، المشي على أطراف الأصابع؛ من الكاميرا أو من فيديو مسجّل. ويفصل الأفعال المتزامنة، ويسجّل المحجوب «غير قابل للتحديد» والحركة التي لا تطابق أي تعريف «خارج الفئات» للاطلاع.
- التحليل داخل المتصفح بنموذج تقدير الوضعية MediaPipe Pose؛ لا يُرسَل الفيديو ولا يُحفظ.
- كل حدث يُحفظ «مقترحًا» حتى يعتمده الأخصائي، ويُحسب الاتفاق بين الملاحِظَين (IOA) مع الأخصائية.
- الحفظ: إذا كانت قيم `config.js` فارغة تبقى البيانات في متصفح الجهاز (وتُنقل بالتصدير والاستيراد JSON). وإذا مُلئت بإعدادات Supabase يصبح الحفظ في قاعدة بيانات مشتركة لا يدخلها إلا أعضاء الفريق.

## تفعيل قاعدة البيانات المشتركة

1. أنشئي مشروعًا مجانيًا في supabase.com.
2. من SQL Editor شغّلي ملف `database.sql`.
3. من Authentication > Sign In / Providers: أوقفي «Allow new users to sign up»، ثم من Users أضيفي حسابات الفريق (Add user).
4. من Project Settings > API انسخي Project URL والمفتاح العام (anon / publishable) وضعيهما في `config.js`. لا تضعي مفتاح service_role أبدًا.

الملفات في مجلد `mp/` هي ملفات نموذج MediaPipe Pose (رخصة Apache 2.0)، وبعضها مسمّى بامتداد `.wasm` ليُخدَم كملف ثنائي.
